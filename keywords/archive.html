01 / CONTEXT

일단 저장하는 시대, 무엇을 남길 것인가

저장인류(All Is Saved: Homo Archivarius)는 일상의 순간과 흔적을 먼저 저장하고 이후의 활용을 생각하는 아카이빙 태도를 설명합니다. 대용량 저장 매체와 기록 도구가 접근성을 높이고, AI는 저장된 정보를 다시 찾고 활용하는 가능성을 넓힙니다.

『트렌드 코리아 2027』 핵심 개념

저장이 쉬워질수록 생기는 세 가지 변화

  1. 일상의 아카이빙화

    사진·회의·대화·방문 장소까지 기록 범위가 넓어집니다. 무엇을 남길지 오래 고민하기보다 ‘일단 저장하고 나중에 활용한다’는 습관이 나타납니다. 다만 저장·보관·정리·보안 비용이 모두 사라지는 것은 아닙니다.

  2. 저장과 인증이 행동의 목적이 된다

    달리기 경로에 강아지 모양 같은 그림을 남기는 방식처럼, 기록할 결과가 활동의 경로와 방식을 결정하기도 합니다. 경험을 남기는 일이 경험을 설계하는 일로 확장됩니다.

  3. 저장 인플레이션과 기억의 역설

    기록은 많아져도 다시 찾고 의미를 붙이지 않으면 활용되지 않은 데이터로 남습니다. 촬영과 인증에만 집중할 때는 직접 느끼고 기억하는 경험이 충분히 쌓이지 않을 수 있습니다.

네 가지 저장·활용 방식

  1. 캡처 · Capture

    순간을 직접 포착하다

    사진·영상·메모·운동 동선처럼 일상의 장면과 행동을 의식적으로 남깁니다. 기록의 시작점은 개인이 선택한 순간입니다.

  2. 트레이스 · Trace

    생활의 흔적이 자동으로 쌓이다

    위치 정보·센서·결제 내역 등으로 활동과 주변 환경의 흔적이 자동 기록됩니다. 편의와 함께 수집 범위와 기록에 대한 통제도 중요해집니다.

  3. 스택 · Stack

    여러 기록을 모아 가치를 만들다

    개인의 기록과 공유 데이터가 축적되며 새로운 정보와 관점을 만듭니다. 공동의 아카이브는 기록을 연결하고 맥락을 발견하는 기반이 됩니다.

  4. 메모리 · Memory

    기록을 추억과 자산으로 재구성하다

    생성형 AI로 저장된 데이터를 요약하고 연결해 회고·개인 자산·추억으로 바꿉니다. 재구성 과정에서는 실제 기록과 AI의 해석을 구별해야 합니다.

비즈니스 관점에서 읽기

고객이 더 많이 저장하도록 만드는 데서 나아가 필요한 기록을 찾고, 이해하고, 다시 활용하도록 도와야 합니다. 데이터의 양과 함께 맥락·신뢰·고객이 느끼는 의미를 설계하세요.

데이터의 맥락을 이해하기

03데이터 관리·고객 신뢰

안심하고 기록할 수 있게 만들기

04AI 큐레이션·회고 서비스

저장을 의미 있는 경험으로 바꾸기
